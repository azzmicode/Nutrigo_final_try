# Nutrigo 🥗

Aplikasi antarmuka web *client-side* interaktif yang berfokus di pemrosesan data dan interaksi pengguna melalui manipulasi DOM.

## 🔗 Live Demo
[Lihat Nutrigo secara langsung](https://azzmicode.github.io/Nutrigo_final_try/)

## ✨ Fitur Utama
* **Interaksi Dinamis:** Menggunakan DOM Manipulation murni tanpa framework untuk memperbarui elemen visual secara *real-time*.
* **Desain Responsif:** Tampilan antarmuka yang menyesuaikan dengan berbagai resolusi layar.
* **Client-Side Processing:** Seluruh logika interaksi dan validasi berjalan dengan cepat dan ringan di sisi klien.

## 🛠️ Teknologi yang Digunakan
* HTML5
* CSS3
* JavaScript

## 🚀 Cara Menjalankan Secara Lokal
1. Clone repositori ini: 
   `git clone https://github.com/azzmicode/Nutrigo_Dom_Manipulation.git`
2. Buka folder direktori proyek.
3. Jalankan file `index.html` di browser Anda, atau gunakan ekstensi *Live Server* pada teks editor.
